# Hospital Management System

A simple console-based Hospital Management System built with Python.

This project was created to practice **Object-Oriented Programming (OOP)** concepts in Python.

## Features

* Add and remove doctors
* Add and remove nurses
* Add and remove patients
* Add and remove departments
* Create and manage rooms
* Manage patient treatments
* Manage doctor and nurse patients
* Update contact information
* Basic room management

## OOP Concepts

The project uses:

* Classes and Objects
* Inheritance
* Encapsulation
* Methods
* `super()`
* Lists for storing objects

### Main Classes

* `Person`
* `Doctor`
* `Nurse`
* `Patient`
* `Department`
* `Room`

## Technologies

* Python
* Object-Oriented Programming (OOP)

## How to Run

Make sure Python is installed, then run:

command-line
python hospital.py


The program provides a console-based menu for managing the hospital system.

## Note

This is an educational project and stores data temporarily in Python lists. Data is not saved after the program is closed.
